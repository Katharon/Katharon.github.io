# Lukas Stumpfel — Blackline portfolio

Responsive redesign of the supplied Next.js portfolio. Website content, projects, contact details, EN/DE routes, CV and original project assets are preserved. The visual system uses locally hosted Geist fonts, dark graphite surfaces, an amber accent and two supplied photographs: the black Milad Fakurian motif in dark mode and the orange Pawel Czerwinski motif in light mode. The selector offers only light and dark. Decorative numbered section rules are intentionally absent.

## Local development

Use Node.js 24 and npm.

```sh
npm ci
npm run dev
```

The English route is `/`, German is `/de/`.

## Production and GitHub Pages

```sh
npm run build
npm start
```

The build generates shared design tokens, then exports static files to `out/`. `npm start` and `npm run preview` serve that export at `http://127.0.0.1:3000`. Set `PORT` to use another local port. A Node.js server is not required in production; the existing GitHub Pages workflow publishes `out/`.

## Design system and HTML styleguide

- `/styleguide/`: interactive reference, shipped with the static website.
- `styleguide.html`: portable single-file HTML reference, generated by `npm run styleguide:export`.
- `public/design/tokens.json`: W3C DTCG-style tokens, raw palette and semantic aliases.
- `public/design/tokens.css`: generated CSS custom properties.
- `public/design/primitives.css`: shared native HTML components and typography.
- `docs/DESIGN.md`: implementation rules, component contracts and UX guidance.

Edit the definitions in `scripts/build-design-tokens.mjs` and run `npm run design:tokens`. The build runs this automatically. Components consume semantic variables such as `--color-accent`, `--color-heading`, `--space-6` and `--font-size-body`. These variables work in Next.js and plain HTML/CSS.

## Files and dependencies

Content lives in `data/`. Sections are server-rendered. Only mobile navigation and the theme selector require client enhancements. A native disclosure keeps the mobile navigation usable without JavaScript. All page content is visible on first render; no animation library is required.

The original images and CV remain under `public/`. `public/images/hero-blackline.webp` is an optimized copy of the user-supplied photograph `milad-fakurian-7W3X1dAuKqg-unsplash.jpg` by Milad Fakurian, [source](https://unsplash.com/photos/7W3X1dAuKqg). `public/images/hero-light.webp` is an optimized copy of the supplied `pawel-czerwinski-yn97LNy0bao-unsplash.jpg`, [source](https://unsplash.com/photos/yn97LNy0bao). The requested degree spelling is BSc. in both languages. Font licensing is included at `public/fonts/OFL.txt`.
